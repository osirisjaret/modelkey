安装三步骤

  1. 激活手表 「开发者模式」

    进入手表「设置 → 关于手表 → 版本信息」，在「版本号」上连续点击7次，激活「开发者模式」

  2. 开启 USB 或 WLAN（Wi-Fi） 调试

    进入手表「设置 → 其他设置 → 开发者模式」中开启 USB 或 WLAN（Wi-Fi） 调试

  3. 连接电脑，使用 adb 安装

    手表连接电脑后，电脑终端命令行运行 adb install 

请自行搜索下载 ADB 程序工具 或 寻求 AI Agent 工具进行协助安装。

FAQ

常见问题

还有疑问？先看这里，大部分情况都覆盖到了。

支持哪些手表？

运行 WearOS 或基于 Android 开发的智能手表，系统需 Android 8.1 及以上。

支持哪些特斯拉车型？

目前只支持 Model 3 / Model Y。首次配对须在车内用原车钥匙卡片在中控感应区完成蓝牙钥匙的授权添加流程。

没有网络能用吗？

可以，Model Key 是纯离线应用。解锁、查看电量与空调控制都在车旁蓝牙连接下完成，地下车库、山区无信号都不影响。

需要登录特斯拉账号吗？

不需要。创建钥匙、无感解锁、查看电量和控制空调都不要求登录账号，也不会把账号信息写进手表。

车辆数据会被上传吗？

不会。数据的生成和保存都在手表本地，不上传、不同步，不收集车辆或账号数据。删除车钥匙或应用后，数据也同时会被清空。

可以远程控制车辆吗？

不可以，因为 Model Key 不接入网络和用户账号，无法对车辆进行远程控制等操作。

如何将应用安装到手表？

请先确认手表已经开启「开发者模式」，在进入「开发者模式」，开启 USB 调试或 ADB 调试下的蓝牙调试 / Wi-Fi（WLAN） 调试后，通过 adb install 指令进行安装。如对于安装步骤有疑惑，也可使用 Codex、WorkBuddy、Trae、豆包工作等 AI Agent 工具进行协助安装。
